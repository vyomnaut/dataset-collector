    How to capture a good training photo

    This dataset trains waste-detection models (YOLOv8 / RT-DETR) on two classes. Good, varied photos matter more than a large number of similar ones.

    small_object

    • The waste item should look genuinely small in the frame — roughly 5–15% of the total image area, not zoomed in.
    • Shoot from a normal standing/eye-level distance, the way a real detection camera would see it.
    • Keep the item fully visible and unblocked — this class is about scale, not occlusion.
    • Vary the background: floor, grass, road, bin area, sorting belt — real-world clutter is good, not a problem.
    • Vary distance and angle across photos — don't shoot every item from the same height and spot.

    occluded_image

    • Part of the object should be genuinely blocked — by another item, a bag, a hand, a bin edge, shadow, etc.
    • Enough of the object should still be visible that a person could still identify what it is.
    • Vary how much is hidden across your shots — some barely occluded, some mostly hidden — rather than all photos looking the same.
    • Object size can be anything here — this class is about occlusion, not scale.

    General rules for both

    • Hold the phone steady — blurry photos get flagged and are usually not worth uploading.
    • Use good, even lighting where possible. Avoid strong backlight that turns the object into a silhouette.
    • Don't shoot the exact same object/angle repeatedly — the duplicate check will flag near-identical photos, and the model learns nothing new from them.
    • One primary object per photo, unless you're intentionally capturing a cluttered scene.
    • Real environments beat staged ones — actual streets, bins, and waste piles train a better model than a clean desk setup.
